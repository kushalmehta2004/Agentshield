Open Source Roundup — November 2024

Five projects worth watching this month:

  1. LiteLLM — unified interface for 100+ LLM providers. Incredibly useful for switching models.
  2. Instructor — structured output extraction from LLMs using Pydantic schemas.
  3. Pydantic AI — agent framework built on Pydantic. Type-safe tool calls.
  4. DSPy — programming model for LLMs. Replaces prompt engineering with optimization.
  5. Marimo — reactive Python notebooks. Git-friendly and reproducible.

All five are worth at least an afternoon of exploration. Links in the footer.
